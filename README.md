# ⚡ NairaVolt: From Watts to Wealth

**NairaVolt** is an energy management application built to help Nigerians track electricity costs, manage tariffs, and eliminate energy waste.

## 🌟 3MTT Impact Pillars
* **Financial Inclusion:** Provides cost transparency (including 7.5% VAT) to help SMEs and households budget accurately.
* **Environmental Sustainability:** Identifies "Heavy Hitter" appliances to encourage energy conservation.

## 🚀 Key Features
* **Real-time Naira Calculation:** Converts Watts to Naira based on NERC rates.
* **"Heavy Hitter" Tags:** Visual alerts for high-drain appliances.
* **VAT Integration:** Automatic 7.5% VAT inclusion.

## 🛠️ Technical Stack & AI Disclosure
* **Stack:** React, Tailwind CSS, Supabase.
* **AI Tools:** Built using **Lovable** and **Gemini** for UI prototyping and logic structuring.

## 📈 Scalability
Designed to scale across all 11 Nigerian DisCos and all tariff bands (A-E).
